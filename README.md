## Repository Structure

This repository contains the data-processing scripts, statistical analysis code, tabular results, and figures used in the study.

### Data preparation

The [`data/`](./data/) directory contains the files used for data acquisition, cleaning, validation, and exploratory analysis.

- [`data/data_eu/`](./data/data_eu/) contains the Exoplanet.eu datasets used at different stages of data preparation.
- [`data/data_nasa/`](./data/data_nasa/) contains data obtained from the NASA Exoplanet Archive for cross-checking and correcting selected observations.
- `1_download_csv.py`, `2_sort_planets.py`, `3_fixed_with_nasa.py`, and `4_count_properties.py` form the main data-preparation sequence.
- `a_download_NASA_data.py` and `b_single_star_system.py` provide additional data collection and system-level processing.
- `properties_distribution.py` and `ranking.py` perform exploratory distribution and ranking analyses.
- `age_plot_count_summary.csv` summarises the numbers of complete observations available for the age–property analyses.
- The PNG files in this directory contain the generated distribution figures.

### Main age–property analysis

- [`age_props_code.py`](./age_props_code.py) defines the main analysis function. It calculates Spearman correlation coefficients, fits linear and quadratic OLS regression models with cluster-robust standard errors, calculates model statistics, and generates regression plot and residual plots.
- [`age_props_call.py`](./age_props_call.py) calls the main analysis function for the selected planetary properties.
- [`age_property_results.csv`](./age_property_results.csv) contains the numerical results from the age–property regression models.
- [`regression_plots/`](./regression_plots/) contains the linear and quadratic regression figures with 95% confidence intervals.
- [`residual_plots/`](./residual_plots/) contains the corresponding residual diagnostic plots.

### Additional analyses

- [`mass_radius_ls.py`](./mass_radius_ls.py) analyse the relationships between mass and radius.
- [`mass_radius_ls.png`](./mass_radius_ls.png) is the figure generated by these analyses.
- [`radius_mass_code.py`](./radius_mass_code.py) performs the age–radius sensitivity analysis with planetary mass included as an additional explanatory variable.
 [`age_radius_mass_sensitivity.csv`](./age_radius_mass_sensitivity.csv) contains the results of this sensitivity analysis.
